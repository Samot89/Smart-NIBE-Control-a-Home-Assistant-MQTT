# ❓ FAQ

### Proč nepoužíváte DM?
DM je hrubý nástroj. Offset křivky je plynulejší a šetrnější.

### Proč jen jeden registr?
Minimalizace konfliktů a předvídatelné chování.

### Funguje to bez nibepi?
Ano, s jakýmkoli Modbus ↔ MQTT bridge.

### Je to vhodné pro radiátory?
Primárně pro podlahovku. Radiátory vyžadují jiné koeficienty.
